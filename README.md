# Retail Sales Analytics

## Project Overview

This project analyzes retail sales data using SQL, Python, Excel, and Power BI to identify sales trends, customer behavior, and business performance.

## Objectives

- Clean and transform retail sales data
- Analyze sales performance using SQL
- Perform exploratory data analysis using Python
- Build an interactive Power BI dashboard
- Generate business insights

## Tools Used

- SQL
- Python (Pandas, NumPy)
- Microsoft Excel
- Power BI
- GitHub

## Dataset

- 10,000 Retail Sales Records
- Customer Information
- Product Categories
- Sales Amount
- Profit
- Region
- Order Date

## Key Insights

- Highest revenue category
- Best-performing region
- Monthly sales trend
- Top customers
- Profit analysis
